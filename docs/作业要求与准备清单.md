| Task 2：Project Charter（Template 3） | 30% | 附件：2026-12-08 23:59；尚未核实独立 Moodle 条目 | 提前完成审阅；不把附件日期称为已核实平台日期 |
| Group Presentation | 5% | 2026-12-10 | 五人均准备发言和答问 |

原文写 “develop an IT project”，但所列交付物**没有代码、源码或 APK 的明文提交要求**；不能由此推定必须交安装包，也不能宣称开发已经完成。[R：P6、P46–47、P81–82]

原文**没有录像替代演示的许可，也没有录像时长、格式、命名的明文规定**。Task 1 建议 6–8 分钟、Task 2／最终演示建议 8–10 分钟，均为排练建议，不是教师规定。视频能否代替现场、如何提交仍须确认。[R：P47、P82、T3R10、T4R12]

团队章程可参考模板发挥创意，并非强制逐项照搬排版，但应覆盖评分项。模板还列目标、价值观、伦理、规则与签署；学号、联系、技能及会议安排不得编造。[R：P41；T：P31–32、P43–57、P113–413]

## 4. 统一项目计划口径

- 以新项目提案呈现；移动采集、归档、检索使用 proposed / will，RAG 问答及来源引用为规划功能。开发和验证状态未核实，不写完成开发、测试通过或效果结果。
- 工作量：**90 人时，每人 18h**。预算：shadow labour **MYR 2,250**（MYR 25/h）+ optional allowance **MYR 100** + contingency **MYR 235** = **MYR 2,585**。仅为计划估算，不是支出、已完成工时或确认资金。
- MOV：未来五人测试，使用固定 **fictional collection**，至少四人在 **60 秒内**找到指定文档。记录正确完成与耗时；只有记录 baseline 后才比较，不发明结果。
- 文档交付采用**学校账号 Google Docs + Word／Markdown**，不交付 PDF。这是本组交付安排，不是原文限定格式。引用材料保留真实出处。
