## 4. Shared project-planning baseline

- Present a new project proposal. Use proposed / will for mobile capture, archiving and retrieval; RAG questions and source references are planned features. Development and validation status is unverified; do not claim completed development, passed tests or measured benefits.
- Effort: **90 person-hours, 18h per member**. Budget: shadow labour **MYR 2,250** (MYR 25/h) + optional allowance **MYR 100** + contingency **MYR 235** = **MYR 2,585**. This estimate covers course documents and presentation, not actual expenditure, completed hours or confirmed funding; production software development requires a separate estimate.
- MOV: a future five-person test with a fixed **fictional collection**, aiming for at least four to locate a specified document within **60 seconds**. Record correct completion and time; compare only after recording a baseline. Do not invent results.
- Use **school-account Google Docs for collaboration, bilingual Markdown for reference and version storage**; no PDF delivery. This is the group’s arrangement, not a format imposed by the original requirements. Check course requirements for the final submission format. Keep genuine sources for referenced material.
